# PeakResort Analytics Suite

A comprehensive data analytics solution developed as part of the Bolt Data BootCamp Case Competition, aimed at scaling Peak Mountain Resort’s operations through data-driven insights.

## 📊 Project Overview

This project combines financial analysis, safety incident evaluation, and customer feedback through natural language processing (NLP) to provide actionable insights for resort management. The goal is to enhance profitability, optimize resource allocation, and improve guest experiences at Peak Mountain Resort.

---

## 🧩 Key Components

### 1. Natural Language Processing (NLP)
- **Dataset:** 500+ customer reviews
- **Techniques:** 
  - Tokenization and text preprocessing (spaCy)
  - Sentiment analysis (TextBlob, VADER)
  - Named Entity Recognition (NER)
  - Topic modeling (LDA with Gensim)
  - Predictive sentiment classification (scikit-learn, 89% accuracy)
- **Insights:** Identified key themes in customer satisfaction and frequent complaints

### 2. Financial Analysis
- **Dataset:** Categorized resort expenses and revenue
- **Tools:** Pandas, NumPy, custom Python scripts
- **Focus Areas:** 
  - Cost of Goods Sold (COGS)
  - Gross profit and margin calculations
  - Expense breakdowns by department
- **Outcome:** Highlighted high-cost areas and revenue optimization strategies

### 3. Incident Report Analysis
- **Dataset:** 1000+ incident logs
- **Objectives:** 
  - Detect patterns in injuries and emergency responses
  - Understand common causes of safety issues
  - Quantify response time and gear usage
- **Methods:** Exploratory data analysis (EDA), visualizations, summary statistics

---

## 🛠️ Tech Stack

- **Languages:** Python
- **Libraries:** spaCy, TextBlob, VADER, Gensim, scikit-learn, Pandas, NumPy, Matplotlib, Seaborn
- **Tools:** Jupyter Notebook

---

## 📈 Outcomes

- Achieved 89% predictive accuracy on customer sentiment classification
- Identified major drivers of cost and safety concerns
- Proposed data-driven strategies for marketing, operations, and safety improvements
- Enabled better prioritization of guest experience upgrades and staffing needs
